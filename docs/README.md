**The generated three are not edited by hand.** After adding or changing a skill
or an agent:

```bash
python scripts/brain/docs.py          # --check exits 1 when stale
python scripts/brain/dashboard.py     # --open to view it
python scripts/brain/site.py          # --open to view it
```

`scripts/brain/health.py` reports stale docs at session start, so you will be
told rather than having to remember.

The maintenance cycle itself is `/brain:ops-maintain`.

## Viewing the HTML dashboard on GitHub

GitHub **sanitizes HTML inside markdown** -- no CSS, no scripts -- so
`dashboard.html` cannot render in a README. Two ways round it:

1. **[DASHBOARD.md](DASHBOARD.md)** -- the same numbers as markdown tables plus a
   mermaid chart, which GitHub renders natively. Regenerated by the same script.
2. **GitHub Pages** -- Settings -> Pages -> source `main` / `/docs`. The
   interactive page is then live at
   `https://<user>.github.io/<repo>/dashboard.html`, sorting and filtering intact.

Pages serves whatever is in `docs/`, so treat that folder as public: never put a
score registry, a journal entry or anything client-specific there.
